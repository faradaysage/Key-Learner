# ABC icon

Generated with the built-in image generation tool. The Google fonts used in the game are Fredoka and Baloo Bhai 2; their OFL notices ship alongside the content. The icon is generated artwork, not a literal rendering of those font files.

Prompt: A square Windows app icon for KeyLearner: oversized rounded balloon-like ABC letters in primary red, yellow and blue, compact readable composition, tactile toy depth, restrained highlights, dark navy rounded-square tile, transparent outside, no other text or symbols.

Master: keylearner-logo.png. Windows ICO: KeyLearner.ico (16 through 256 px). Runtime window/taskbar icon: window-icon.png. Regenerate sizes with scripts/build-icon.ps1.

The game uses weight-650 static instances of the bundled Google variable fonts. Reproduce them with `scripts/prepare-fonts.py` (requires fontTools); original font files and OFL notices are retained.
