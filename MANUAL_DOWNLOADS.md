# Manual asset downloads

Current playable content is supplied. The optional volcano and eagle sources below still require manual downloads.

The user supplied all six **Coral Reef Kit** FBXs and **Seaweed by Mohabins** in `_asset_inbox`. The user also confirmed the Coral Reef Kit credit/license as **MiniPoly, CC BY 3.0**. Original source colors and textures have been recovered and retained.

- [Coral Reef Kit by MiniPoly](https://poly.pizza/bundle/Coral-Reef-Kit-ghN8EmbYa6)
- [Seaweed by Mohabins](https://poly.pizza/m/oYxUdpyc4u)

Poly Pizza was not accessed automatically. Future replacements from that site must follow the same manual handoff. Existing packs, including the rigged bird and nineteen marine species/models, were obtained locally without authentication. See `THIRD_PARTY_ASSETS.md` for exact imports and credits.


## Supplied Arctic wildlife (September 2026)

Both polar bears have been supplied. The shipped selection is **Polar Bear by kenchoo**, https://skfb.ly/oRMzK, CC BY 4.0, with its original source animation. Blender converts the GLB to FBX using `scripts/convert-animated-polar-bear.py`. The earlier static Gouw `.blend` remains in the local inbox; it is not needed by the distributed build.

The user also supplied WildMesh's animal pack and explicitly authorized its CC BY-NC 4.0 license. See `NONCOMMERCIAL_ASSETS.md` before commercial distribution.
