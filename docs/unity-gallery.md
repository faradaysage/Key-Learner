# Actual Unity gameplay

These are screenshots from the Windows player at its real gameplay camera, downscaled from 1366 x 768 to 1280 x 720. They are not Editor scene views or concept art. Original PNGs, player logs and diagnostic JSON are retained under `artifacts`; [sources.json](screenshots/unity/sources.json) maps each gallery image to its capture. See [verification](unity-verification.md) for measured conditions and limitations.
